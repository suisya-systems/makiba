# M3-5 Startup dialogs

## Before starting

Do not start until probes P1 to P5 and P7 to P11 are recorded as run, with versions and date, in `docs/design/probes.md` (Results). They are run by hand before any Issue of M2 or M3, on the pinned base version. A probe run in part names the steps not run; those are run before the Issue that relies on them lands.

## Why

A blind Enter once ended a terminal because the dialog's default line had changed (I-2).

## What to build

- `src/daemon/dialogs.rs`: while a launched terminal has no status, read its screen; ask the agent module's policy list whether a known dialog is shown; if so move the cursor toward the expected line, read again, and press the key only when the cursor is on it and the option lines still match whole.
- A dialog not on the list: no key. The launch fails with `worker_spawn_failed` carrying the screen text.
- `run_launch.stage = dialog_passed` (also when no dialog appeared and a status arrived).
- The matcher is ported from the runtime's `decide`, with its cases; the press rule is paddock's.
- The policy list of the Claude Code module has two entries, `folder-trust` and `dev-channel` (spec section 7); the second is passed by choosing its line 1.

## Carried from

- claude-org-runtime 0.1.58: `claude_org_runtime/dispatcher/spawn_prompt.py` (`decide`, `screen_lines` and helpers)
- paddock: the policy-list rule in `skills/org-escalation` and inventory row L-N3

## Definition of done

The first commit adds `tests/startup_dialog.rs`, failing, with the trailer `Acceptance-Test: tests/startup_dialog.rs`. At head `cargo test --test startup_dialog` passes and asserts:

- A folder-trust dialog whose cursor starts on 'No, exit' ends with the trust line chosen and the agent running.
- The same dialog with one option line reworded is not answered, and the launch fails with the screen recorded.
- No key is ever sent to a terminal that has a status.
- The development-channel dialog, shown after the trust dialog as P10 recorded it, ends with line 1 chosen; the same dialog with one option line reworded is not answered.
