# M0-8 The shared specification, checked against the code

## Why

M2 and M3 are built in parallel. Without one place that fixes table columns, tag keys, event kinds and exit codes, each worker invents its own.

## What to build

- `docs/design/spec.md` as delivered, reviewed and corrected against the carried schema.
- `src/spec.rs`: the same names as constants and enums (the two wrapper sentences of section 8, the wake line of section 7, tag keys, event kinds, the door's `ErrorKind` and its exit codes, agent ids, verbs per role, the wrapper's limits).
- A test that reads the tables of `spec.md` and compares them with `src/spec.rs`.

## Definition of done

The first commit adds `tests/spec_matches_code.rs`, failing, with the trailer `Acceptance-Test: tests/spec_matches_code.rs`. At head `cargo test --test spec_matches_code` passes and asserts:

- Every tag key, event kind, error kind, exit code and verb in the document equals the constant, both ways.
- Removing one name from either side fails the test.
