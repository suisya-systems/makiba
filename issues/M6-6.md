# M6-6 Conveyor and the acceptance gate

## Why

The acceptance gate is what lets pull requests merge without a person reading each one. It reads `ci_completed` rows, which M5-3 now writes.

## What to build

- The gate logic of `acceptance_gate.py` and `acceptance_merge_hook.py`, ported with the cases of their tests, and the secretary's `PreToolUse` hook as the subcommand `makiba hook merge-gate`; they read `state.db` through a read-only query `makibad` answers over the door.
- `skills/conveyor`, rebuilt from claude-org-ja's, with `merge_approval_mode` in the organization settings.
- The hook also refuses the other ways to merge from a command line: the pull-request merge command with any flag, the API command with a write method on a `pulls/<n>/merge` path, its GraphQL form carrying a merge mutation, and `curl` or `wget` to the GitHub API.

## Carried from

- claude-org-ja: `tools/acceptance_gate.py`, `tools/acceptance_merge_hook.py`, `.hooks/gate-acceptance-before-merge.sh`, `tools/test_acceptance_gate.py`, `tools/test_acceptance_merge_hook.py`, `.claude/skills/org-conveyor/` (translated)

## Definition of done

The first commit adds `tests/acceptance_gate.rs`, failing, with the trailer `Acceptance-Test: tests/acceptance_gate.rs`. At head `cargo test --test acceptance_gate` passes and asserts:

- The cases of the carried gate tests, ported, pass.
- A merge command for a pull request with no declared test is refused in `acceptance` mode.
- A merge is refused when the latest `ci_completed` is for another head.
- Each of the other ways above is refused in `acceptance` mode, and a command that only mentions them as an argument is not.

## Notes

A hook reads command text and cannot list every way to reach GitHub. It is kept for the ways above and is not the bound. The bound is on GitHub's side: branch protection that requires the `acceptance` check and lets nobody, the person's own login included, merge around it. M0-1 names that setting for this repository; for every other project it is the owner's to set, and makiba does not set it.
