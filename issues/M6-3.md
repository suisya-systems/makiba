# M6-3 The secretary's skills, operating no terminal

## Why

paddock's skills are in English and have run the full loop, but they call `hc` and the shell mailbox. claude-org-ja's name pane tools seventy times.

## What to build

- `skills/`: `delegate`, `escalation`, `pull-request`, `issue`, `update-branch`, `curate`, rebuilt from paddock's. Every `hc` call and every `org` mailbox call becomes a tool call of the door (spec section 12); scripts that only wrapped `hc` are deleted.
- `skills/retro`: the retrospective the model dispatcher used to write, as a secretary skill.
- `skills/document`: how a document request runs. The secretary dispatches a maker with `--kind document`; when it reports, a second worker reads the draft against the request and checks that each fact carries a source; only then does the secretary hand the result to the person. Borrowed as rules from libretto; none of libretto's code or services is used.
- `roles/secretary/rules.md`: roles, the lines the secretary holds, situations mapped to skills. It says when to send `typed` (spec section 7): when a message that came by channel was refused as not being from the person, send it again with `typed`; send an instruction known from the start to need typing typed at once; never to the secretary. `makibad` cannot see a refusal, so the sender reads the answer.
- `tests/no_terminal_tools.rs`: fails when a file under `skills/` or `roles/` names `hc `, `herdr`, `send_keys`, `inspect_pane`, `list_panes`, `spawn_pane`, `close_pane`, `tmux` or `wezterm`. The check is the test, run by `cargo test` in CI.

## Carried from

## Definition of done

The first commit adds `tests/no_terminal_tools.rs`, failing, with the trailer `Acceptance-Test: tests/no_terminal_tools.rs`. At head `cargo test --test no_terminal_tools` passes and asserts:

- The check passes on the repository.
- A scratch skill containing `hc send` fails its scan.
- Every tool or command a skill names is a verb of the table in spec section 12.
- `roles/secretary/rules.md` names `typed` and says both when to use it and that it never goes to the secretary.
- `roles/secretary/rules.md`, as rebuilt here, still contains the two wrapper sentences of spec section 8.
