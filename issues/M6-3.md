# M6-3 The secretary's skills, operating no terminal

## Why

paddock's skills are in English and have run the full loop, but they call `hc` and the shell mailbox. claude-org-ja's name pane tools seventy times.

## What to build

- `skills/`: `delegate`, `escalation`, `pull-request`, `issue`, `update-branch`, `curate`, rebuilt from paddock's. Every `hc` call and every `org` mailbox call becomes a `makiba` command; scripts that only wrapped `hc` are deleted.
- `skills/retro`: the retrospective the model dispatcher used to write, as a secretary skill.
- `skills/document`: how a document request runs. The secretary dispatches a maker with `--kind document`; when it reports, a second worker reads the draft against the request and checks that each fact carries a source; only then does the secretary hand the result to the person. Borrowed as rules from libretto; none of libretto's code or services is used.
- `roles/secretary/rules.md`: roles, the lines the secretary holds, situations mapped to skills.
- `tools/check_no_terminal_tools.py`: fails when a file under `skills/` or `roles/` names `hc `, `herdr`, `send_keys`, `inspect_pane`, `list_panes`, `spawn_pane`, `close_pane`, `tmux` or `wezterm`.

## Carried from

- paddock: `skills/org-delegate`, `org-escalation`, `org-pull-request`, `org-issue`, `org-update-branch`, `org-curate`
- claude-org-ja: `.claude/skills/org-retro/` (translated), `.dispatcher/references/rationale.md` (translated, as `docs/rationale.md`)

## Definition of done

The first commit adds `tests/test_no_terminal_tools.py`, failing, with the trailer `Acceptance-Test: tests/test_no_terminal_tools.py`. At head it passes and asserts:

- The check passes on the repository.
- A scratch skill containing `hc send` fails it.
- Every command a skill names exists in `makiba --help`.
- `roles/secretary/rules.md`, as rebuilt here, still contains the wrapper sentence of spec section 8.
