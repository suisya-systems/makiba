# M4-5 One real worker, request to done report

## Why

Everything before this ran the test agent. This is the first time Claude Code is launched by makibad.

## What to build

- A written procedure, `docs/runbooks/first-worker.md`: preconditions (probe P1 passed, a trusted scratch repository), the commands, what to look at.
- Run it on a host: `makiba up --no-secretary`, a `dispatch` typed by the person, the worker edits one file and calls the tool `report` with `done`, the person runs `makiba close`.
- Inside the worker, ask it to run the base's command, to connect to the base's socket, to read the person key file, to call the door's port with no token and with an invented one, and to look for its own token (its environment, `/proc`, the files it can read); record the refusals.
- Record versions, date and what happened in the runbook's results section. File an Issue for every surprise.

## Definition of done

Checked by a person:

- The run reaches `review` with no person typing into the worker's terminal.
- `worker_spawn_verified` and `report_done` are in `events`.
- The two attempts to reach the base from the worker are refused.
- The read of the person key file is refused, a call to the door's port with no token or an invented one is `denied`, and the agent's token is found nowhere the worker can read.

## Notes

No failing test can come first: this is a host run with a real agent. It is outside the acceptance gate and is closed by a person on the recorded result.
