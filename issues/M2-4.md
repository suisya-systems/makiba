# M2-4 Deliver messages

## Before starting

Do not start until probes P1 to P5 and P7 to P11 are recorded as run, with versions and date, in `docs/design/probes.md` (Results). They are run by hand before any Issue of M2 or M3, on the pinned base version.

## Why

Three incidents were about a message that did not arrive or arrived by a route nobody read (I-3, I-5, I-7). makiba has one route, and a ledger that shows what is still undelivered.

## What to build

- `makiba/daemon/delivery.py`: each pass, for every `pending` delivery, find the recipient's terminal by name; if its status is `idle` or `done`, type the wrapped text of spec section 8 with `Base.send`; mark `delivered`, or `failed` with the error and try again next pass.
- Never type to `working`, `blocked`, `error` or a terminal with no status.
- Several pending messages for one recipient go in one send, oldest first, within the limit; bodies over the limit are cut with the `makiba show` line.
- `attempt` counts passes in which a send was tried, as in claude-org-ja's ledger.

## Definition of done

The first commit adds `tests/test_delivery.py`, failing, with the trailer `Acceptance-Test: tests/test_delivery.py`. At head it passes and asserts:

- A message to a working agent stays `pending`; when the agent turns `idle` the next pass delivers it once.
- A send that raises leaves the row `failed` with the error; the next pass delivers it.
- Killing `makibad` between the send and the ledger write, then restarting, does not lose the message (it may be typed twice; the test asserts at-least-once and that the row ends `delivered`).
- Every typed text begins with `<makiba ` whatever the body is, and a body containing `</makiba>` cannot close the wrapper.
- A body over the limit is cut and carries the `makiba show <id>` line.

## Notes

Probes P3 and P4 measure what the test agent cannot: a person's half-typed draft, and how a real composer takes multi-line and slash-leading text. P4 passed for a terminal nobody types in. P3 failed in keys mode and with a person typing: typed text joins a person's draft (hc 0.1.20 in paddock's measurement, hc 0.1.21 here). Decision pending (owner): delivery (plan.md section 3.3). The first candidate is a box in `makibad` with a Claude Code channel as the first route, the base's status to confirm that a turn started, and one fixed typed line as the fallback; P8 to P10 measure it. Do not start this Issue's delivery pass until it is decided. Typed delivery as written here is the fallback of that candidate, and the route for workers and the curator if it is not taken.
