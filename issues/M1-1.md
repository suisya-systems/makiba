# M1-1 Connect to the base and say hello

## Why

Every later call rests on one connection that knows what it is talking to.

## What to build

- `makiba/base/__init__.py`: the `Base` protocol, the data classes and the error types of spec section 6.1.
- `makiba/base/herdr.py`: `hello()`. Resolve the socket (`$XDG_RUNTIME_DIR/herdr-core/<session>.sock`), connect, send `hello`, check version and protocol generation.
- `tools/check_base_seam.py`: fails when a file under `makiba/` outside `makiba/base/` imports `makiba.base.herdr` or names `herdr` or `hc`. The base is a part that can be replaced (plan.md, "The measure"); this keeps it one.
- A timeout per call; no retry here.

## Definition of done

The first commit adds `tests/test_base_connect.py`, failing, with the trailer `Acceptance-Test: tests/test_base_connect.py`. At head it passes and asserts:

- `hello()` against the stand-in returns the base's name and version.
- A base outside the supported range raises `UnsupportedVersion` and no other request is sent.
- A base that is not running raises `Unavailable`, not a traceback from `socket` or `subprocess`.
- `tools/check_base_seam.py` passes on the repository, and fails on a scratch module outside `makiba/base/` that imports `makiba.base.herdr`.

## Goal clause

- G6 The base is a part that can be replaced, and an update of it does not break makiba
