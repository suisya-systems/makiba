# M1-1 Connect to the base and say hello

## Why

Every later call rests on one connection that knows what it is talking to.

## What to build

- `src/base/mod.rs`: the `Base` trait, the types and the `BaseError` enum of spec section 6.1.
- `src/base/herdr.rs`, a private module of `base`: `hello()`. Resolve the socket (`$XDG_RUNTIME_DIR/herdr-core/<session>.sock`), connect with std's `UnixStream`, send `hello` as JSON-RPC (serde_json), check version and protocol generation.
- `tests/base_seam.rs`: fails when a file under `src/` outside `src/base/` names `herdr` or `hc`. Because `herdr` is a private module of `base`, code elsewhere that imports it does not compile; the test holds the names. The base is a part that can be replaced (plan.md, "The measure"); this keeps it one.
- A timeout per call (the socket's read and write timeouts); no retry here.

## Definition of done

The first commit adds `tests/base_connect.rs`, failing, with the trailer `Acceptance-Test: tests/base_connect.rs`. At head `cargo test --test base_connect` passes and asserts:

- `hello()` against the stand-in returns the base's name and version.
- A base outside the supported range returns `BaseError::UnsupportedVersion` and no other request is sent.
- A base that is not running returns `BaseError::Unavailable`, not a panic or an unmapped `io::Error`.
- `tests/base_seam.rs` passes on the repository, and its scan fails on a scratch tree with a module outside `src/base/` that names `herdr`.
