# M4-2 The sandbox reaches the door and nothing of the base

## Why

A deny rule matches command text; a script or a direct socket connection is outside it. paddock wrote the sandbox entries for herdr-core but could not measure them, because its deny rule always refused first.

## What to build

- Per-task settings (from M3-2) deny the base's socket and state folders and the person key file for read and write, and allow the door's socket.
- `scripts/probes/door-and-base-reach.sh`: probe P1 as a script a person can rerun. P1 was run by hand before M2 and M3 with hand-written settings; this repeats it with the settings `makibad` really writes.
- The result recorded in `docs/design/probes.md` with versions and date.

- paddock: `scripts/probes/core-api-reach.sh`

## Definition of done

- The per-task settings written for a run contain the base's denies, the person key file's denies and the door's allow.
