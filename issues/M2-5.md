# M2-5 Rebuild the view after a restart

## Before starting

Do not start until probes P1 to P5 and P7 to P11 are recorded as run, with versions and date, in `docs/design/probes.md` (Results). They are run by hand before any Issue of M2 or M3, on the pinned base version. A probe run in part names the steps not run; those are run before the Issue that relies on them lands.

## Why

`state.db` holds no terminal address. After `makibad` or the base restarts, the tags are the record.

## What to build

- `makiba/daemon/recover.py`: on start and on every `Resync`, list terminals with `makiba.org`; match each to a run by `makiba.task_id`; write `terminal_gone` for an `in_use` run with no terminal; write `base_resynced`.
- A terminal with the organization's tag and no matching run is reported as an anomaly to the secretary, never ended.

## Definition of done

The first commit adds `tests/test_recover.py`, failing, with the trailer `Acceptance-Test: tests/test_recover.py`. At head it passes and asserts:

- Kill `makibad` while an agent runs; the agent then reports `done`; restart; the `done` is recorded.
- A run whose terminal vanished while `makibad` was down gets one `terminal_gone`.
- An unknown tagged terminal is left alone and reported once.
