# M2-6 Tell the secretary only what it can act on

## Before starting

Do not start until probes P1 to P5 and P7 to P11 are recorded as run, with versions and date, in `docs/design/probes.md` (Results). They are run by hand before any Issue of M2 or M3, on the pinned base version. A probe run in part names the steps not run; those are run before the Issue that relies on them lands.

## Why

A secretary woken for every status change stops reading. claude-org-ja's suppression rules already encode what is worth a message.

## What to build

- `makiba/daemon/notify_gate.py`: the carried rule set, applied before a `notice` is queued.
- A suppressed notice is still an event; only the message is skipped.

## Carried from

- claude-org-ja: `tools/notify_gate.py`, `tools/test_notify_gate.py`

## Definition of done

The first commit adds `tests/test_notify_gate.py`, failing, with the trailer `Acceptance-Test: tests/test_notify_gate.py`. At head it passes and asserts:

- The carried tests pass against the carried rules.
- A suppressed anomaly writes `anomaly_raised` and queues no message.
