# M0-7 English only, checked in CI

## Why

The English mirror of claude-org-ja fell five hundred pull requests behind the Japanese source. makiba has one source, in English.

## What to build

- `tools/check_language.py`: fails when a tracked file under `makiba/`, `roles/`, `skills/`, `docs/`, `tests/` or `knowledge/` contains a character from the Hiragana, Katakana or CJK Unified Ideographs blocks.
- An allow-list file for the few places that must hold other languages: `tests/fixtures/i18n/` (text the tests feed in) and `roles/locale/` (the sentence that sets the conversation language).
- A `lint` step in CI.

## Definition of done

The first commit adds `tests/test_check_language.py`, failing, with the trailer `Acceptance-Test: tests/test_check_language.py`. At head it passes and asserts:

- A scratch tree with one kana character in `skills/x.md` fails.
- The same character under `tests/fixtures/i18n/` passes.
- The repository itself passes.
